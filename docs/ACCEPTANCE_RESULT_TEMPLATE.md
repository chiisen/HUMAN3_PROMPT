# 對話驗收結果模板

複製後填寫，每個語言、模型與案例各一份。不可將預期輸出當作實際輸出。正式紀錄須純虛構且去除帳號等識別資訊。

- 執行日期與時區：未執行
- 測試者／方式：未執行（人工／自動；可用匿名代號）
- 服務、模型名稱：未執行
- 模型版本、系統設定、溫度等可取得設定：未執行（服務未提供者明記）
- 提示詞 Git SHA：未執行
- 提示詞檔案與語言：未執行
- 案例 ID／變體：未執行
- 起始條件與共用資料：未執行
- 完整對話或附件路徑：未執行
- 各象限實際題數：未執行
- 八題上限邊界是否到達：未執行
- 判定：未執行（只能選未執行／通過／失敗／未覆蓋）
- 逐條預期及禁止行為的判定與輸出位置：未執行
- 判定理由、限制與重測需求：未執行

## 實際輸入與輸出

未執行。執行後逐輪原樣記錄 user／assistant、象限、該象限累計題數。不可只記模型自稱遵守規則的文字；須檢視實際輸出。

## 與其他驗證的區別

- 本機 unittest／區段檢查：另記命令、結果及版本；不能替代本案例。
- 人工語意校閱：另記對照清單與發現；不能替代本案例。
- GitHub Actions：另記 run URL、commit SHA 與結論；未觸發或未完成就寫明。
- 未執行或未覆蓋的案例不可計入通過率分母，報告需同時揭露總數、已執行、通過、失敗及未覆蓋數，不只報百分比。
