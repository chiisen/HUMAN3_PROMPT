# HUMAN 3.0 自我反思訪談提示詞

本專案提供一組以 HUMAN 3.0 四象限框架為靈感的引導式自我反思提示詞。使用者可透過 AI 對話整理心智、身體、靈性與職業等生活領域的經驗，並獲得暫定觀察與反思問題。

這不是經驗驗證的心理測驗、研究量表、醫療工具或心理診斷。AI 產生的層級、階段、元類型、象限關聯與行動建議，都是依有限對話形成的暫定解讀，可能錯誤或不完整，不應視為客觀測量結果，也不能取代心理、醫療、法律、財務或其他專業評估與建議。

## 適用對象與限制

- 適合想透過結構化提問整理自身經驗、檢視生活模式或產生後續反思方向的成年人。
- 教練、教育工作者或助人專業者，可將其作為對話與反思的輔助材料；不得把 AI 結果當成對他人的診斷、經驗驗證的測量或專業判斷依據。
- HUMAN 3.0 分級不能判定高風險行為是否適合個人，也不能判定其安全性；本框架及 AI 無法評估迷幻藥、PEDs／合成代謝類固醇、刻意製造財務困境或其他高風險行為是否適合你。不要用發展分級作為採取風險的許可；相關健康或物質問題請諮詢合格醫療專業人員，重大財務、工作或法律決策請尋求具相關資格且獨立的專業意見。
- 若對話令你感到不適，請停止使用；若正面臨急迫的身心安全問題，請聯絡當地緊急服務或合格專業人員。

## 隱私與使用前提醒

- 避免輸入姓名、地址、電話、電子郵件、工作單位、帳號、精確日期等可識別身分的資料。
- 也避免貼入病歷、檢驗報告、財務帳戶、法律文件、第三人的私密資訊或其他不願交由 AI 服務處理的敏感內容；需要討論時，先移除身分線索並只提供必要概況。
- 對話會如何儲存、用於訓練或分享，取決於你使用的 AI 服務及帳戶設定。開始前請查看該服務的隱私與資料保留政策；本專案不會替該服務保證保密或刪除資料。
- 只回答自己願意分享的內容。可要求跳過任何問題或停止訪談，不必解釋原因。

## 使用方法

1. 選擇你信任且已了解其隱私設定的 AI 服務。
2. 複製 [英文提示詞](./PROMPT.md) 或 [繁體中文提示詞](./PROMPT_TW.md)，貼入對話並依序回答問題。
3. 不確定或不願回答時，輸入「跳過」；要暫停或結束時，輸入「停止訪談」。回答只提供自己願意分享的資訊。
4. 面談後 AI 會先提供短摘要。請先修正不準確處、補充背景或要求補問；只有在確認或明確要求繼續後，才會產生完整報告。你也可以只要求特定章節，或停留在摘要。
5. 將結果當作待檢視的反思假設。若證據不足，要求 AI 說明未知之處；不要因為某個標籤或建議而做出重大健康、財務、法律或人生決定。

## 提示詞維護

- `PROMPT.md` 為主要維護來源；修改後再將相同意義同步至 `PROMPT_TW.md`。
- 兩份提示詞以 `prompt-parity` 區段標記對應的重要內容，不要求翻譯逐字一致；新增或重組重要區段時，請在兩份文件保留相同的標記 ID：`model-fundamentals`、`high-risk-safety`、`interview-flow`、`report-format`。
- 使用 Python 標準函式庫執行 `python scripts/check_prompt_parity.py`，檢查必要區段是否在兩種語言中成對存在、標記唯一且內容非空，無需安裝額外套件。此檢查不判斷翻譯品質或語意是否完全等價，仍需人工校閱。

## Git 推送遠端設定

在已初始化的 Git 專案目錄內執行 `pwsh -File ./setup_git_sync.ps1`，即可設定本專案預期的五個 `origin` 推送目的地。腳本只替換該 repo 本機設定中的 `remote.origin.pushurl` 清單，執行前後都會顯示所有 remote；不會修改 `origin` 的 fetch URL 或其他 remote。可重複執行；執行前請確認目前所在目錄是要設定的 HUMAN3_PROMPT Git checkout。
