# Dan Koe HUMAN 3.0 提示詞：中英文社群修訂版

把提示詞貼進 AI 對話，透過提問整理心智、身體、靈性與職業四個生活領域的經驗，再檢視 AI 提出的暫定觀察與下一步。

本專案以 Dan Koe 的 [HUMAN 3.0 Self-Discovery & Metatype Test](https://letters.thedankoe.com/p/prompt-human-30-self-discovery-and) 為來源，由社群整理與修訂，並非官方版本。

## 開始使用社群修訂版

不需要安裝程式、Python 或執行測試。

1. 選擇你信任、且已了解其隱私設定的 AI 服務，將上方其中一份修訂版提示詞完整貼入新對話。
2. 依序回答問題，只分享自己願意提供的資訊。你可以要求跳過任何問題或停止訪談，也可以暫停。
3. 訪談後先檢查短摘要，修正不準確處，再選擇完整報告、特定章節或停在摘要。確認並選定範圍後，AI 應直接產出。
4. 修訂版的行動建議預設為一個可逆的小實驗與回顧條件；額外任務或長期規劃只在你要求且有回答依據時展開。

想先看修訂版的輸出形式，可閱讀[合成報告](docs/RESULTS.md)或[簡易摘要](docs/RESULTS_EASY.md)。人物與回答皆為虛構，不能當成實際使用成效。

## 使用前請留意

這適合想整理自身經驗的成年人。它不是經驗驗證的心理測驗、研究量表或心理診斷；AI 給出的層級、類型、原因推測與建議可能錯誤或不完整。若作為教練、教育或助人對話的輔助，也不能把輸出當成對他人的診斷或專業判斷。

- 避免輸入姓名、地址、帳號等識別資訊，以及病歷、財務資料、法律文件或第三人的私密內容。資料如何儲存、使用或分享取決於 AI 服務及帳戶設定；本專案不會替該服務保證保密或刪除資料。
- 框架分級不能判定高風險行為是否適合個人，也不能證明其安全。不要據此決定使用迷幻藥、PEDs／合成代謝類固醇或刻意製造財務困境。健康與物質問題請諮詢合格醫療人員；重大財務、工作或法律決策請尋求具相關資格且獨立的專業意見。
- 對話讓你不舒服時可以停止；若有急迫的身心安全問題，請聯絡當地緊急服務或合格專業人員。
